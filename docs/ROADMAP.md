# Roadmap проекта «Задачник»

## Общий принцип

Разработка ведётся поэтапно.

Не начинать следующий этап автоматически.
После каждого этапа приложение должно оставаться в рабочем состоянии.

Перед завершением этапа:

1. проверить TypeScript;
2. выполнить lint;
3. выполнить `npm run build`;
4. проверить `git status`;
5. сделать commit;
6. при настроенном remote выполнить push в GitHub.

Однозначные включённые границы:

| Оценка | Игры (минуты) | Соцсети (минуты) |
| --- | --- | --- |
| 😄 Отлично | 0–120 | 0–60 |
| 🙂 Хорошо | 121–240 | 61–90 |
| 😐 Нейтрально | 241–329 | — |
| 🙁 Плохо | 330–360 | от 91 |
| 😡 Очень плохо | от 361 | — |

«Около 6 часов» определено как 5:30–6:00 включительно. Ввод поддерживает
0:00–24:00; отсутствие записи отличается от сохранённого нуля.

- Заметки хранятся в необязательном `HabitEntry.note`, только у существующей записи;

- Серии относятся к boolean-привычкам: текущая заканчивается выбранной датой,
  лучшая считается до неё; пропуски прерывают серию, но исключены из success rate.
