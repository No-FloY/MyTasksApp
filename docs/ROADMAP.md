# Roadmap проекта «Задачник»

## Общий принцип

Разработка ведётся поэтапно.

Не начинать следующий этап автоматически.
После каждого этапа приложение должно оставаться в рабочем состоянии.

Перед завершением этапа:

1. проверить TypeScript;
2. выполнить lint;
3. выполнить `npm run build`;
4. проверить `git status`;
5. сделать commit;
6. при настроенном remote выполнить push в GitHub.

  не обрезается. Игры/соцсети показывают среднее по записям и сумму / дни отслеживания.
- relevantTasks = completedOnTime + completedLate + failed + overdue.
  OnTimeRate = completedOnTime / relevantTasks; DeviationRate =
  (completedLate + failed + overdue) / relevantTasks. Отменённые, ожидающие срока
  и выполненные без известного completedAt исключены и показаны отдельно.
- Дедлайн с временем — локальный HH:mm:00.000, без времени — конец локального дня;
  равенство считается своевременным выполнением. Исходы не сохраняются в БД.
- Цели показывают текущее состояние и средний прогресс активных, независимо от
  периода; архивные цели подсчитаны отдельно. История прогресса не выдумывается.
- Архивные привычки сохраняют историю; пустые дни до создания/после архива не
  добавляются. Более ранние записи из календаря уточняют начало отслеживания.
- 3/6/12 месяцев — скользящие интервалы по сегодня; произвольный период до 3660 дней.
  Недели начинаются в понедельник и ограничены выбранными границами.
